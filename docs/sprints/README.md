# Actas de sprint

Una carpeta por sprint: `sprint-2/`, `sprint-3/`, `sprint-4/`, cada una con `planning.md`, `review.md`
y `retro.md`. El Sprint 1 está documentado en el informe técnico entregado (27 sep 2026); su review y su
retrospectiva se registran en `sprint-1/` el 7 de octubre.
